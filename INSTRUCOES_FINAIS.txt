2. ERROS COMUNS:

   ❌ "Cannot find module"
      → Problema com npm install
      → Solução: Verificar package.json

   ❌ "Migration failed"
      → Problema com banco de dados
      → Solução: Verificar DATABASE_URL

   ❌ "Seed failed"  
      → Problema com dados iniciais
      → Solução: Verificar se user já existe

   ❌ "Port already in use"
      → Deploy anterior não terminou
      → Solução: Aguardar ou reiniciar manualmente

3. EXECUTE OS SCRIPTS DE DIAGNÓSTICO:
   bash /home/user/webapp/testar-projeto.sh
