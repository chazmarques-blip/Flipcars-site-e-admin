### **CENÁRIO 3: CPL $30-50 (PRECISA MELHORAR)** ⚠️

```
⚠️ Campanha cara, mas pode melhorar

Ações:
1. ⚠️ Analise deeply o que está errado:
   - CTR muito baixo? (< 1.5%) → Problema no criativo
   - CPC muito alto? (> $2) → Problema no targeting
   - Conversion rate baixa? (< 3%) → Problema no site
2. ⚠️ Faça mudanças significativas:
   - Mude targeting (teste outras cidades?)
   - Troque criativo (teste imagem ao invés de vídeo)
   - Teste objetivo "Traffic" se está em "Conversions"
```

**Plano de resgate:**
```
Opção A: Restart with Traffic objective
- Pause campanha atual
- Crie nova com objetivo "Traffic"
- Use mesmo targeting
- Rode por 7 dias

Opção B: Narrow targeting
- Pause campanha atual
- Crie nova com targeting mais específico:
  - Apenas idade 35-54 (se essa converteu melhor)
  - Apenas Feed placements (sem Stories/Reels)
  - Raio menor (15mi ao invés de 25mi)
```

**Investigação profunda:**
```
Perguntas a fazer:
□ O vídeo está bom? CTR < 1.5% = vídeo ruim
```

## 🔔 ALERTAS - QUANDO SE PREOCUPAR

### **🚨 ALERTA VERMELHO (Agir HOJE):**

```
❌ Spend > $30/dia (extrapolou budget)
   → Ajuste Campaign Budget imediatamente

❌ CTR < 0.8% após 3 dias
   → Troque criativo (vídeo/imagem ruim)

❌ CPC > $3 consistentemente
   → Targeting muito competitivo, mude público

❌ Zero leads após $100 gastos
   → PAUSE e revise tudo (funil quebrado)

❌ Campanha "Not Delivering" ou "Paused"
   → Verifique billing, política, ou erros
```

---

### **⚠️ ALERTA AMARELO (Monitorar):**

```
⚠️ CTR entre 1-1.5%
   → Pode melhorar, teste variações

   → Um pouco caro, monitore

⚠️ CPL entre $30-40
   → Funcionando, mas pode otimizar

⚠️ Conversion Rate < 5%
   → Site ou formulário podem melhorar
```

## 🆘 TROUBLESHOOTING

### **Problema: "Ad not delivering"**
```
Causas possíveis:
❌ Budget muito baixo ($5/dia) → Aumente pra $20+
❌ Targeting muito específico → Amplie audience
❌ Billing issue → Verifique cartão de crédito
❌ Policy violation → Veja notificação do Facebook

Solução:
1. Clique no ícone de alerta
2. Leia mensagem completa
3. Corrija o problema
4. Ad volta a rodar automaticamente
```

---

### **Problema: "Learning Limited"**
```
Causa:
❌ Não atingiu 50 conversões em 7 dias

Solução:
- Mude evento de otimização (Lead → PageView)
- OU aumente budget ($40/dia)
- OU expanda targeting (mais 10mi radius)
- OU combine ad sets similares
```

---

### **Problema: "High CPC" (> $3)**
```
Causas:
❌ Targeting muito competitivo
❌ Criativo ruim (CTR baixo)
❌ Audience muito pequena

Solução:
- Teste targeting diferente
- Melhore criativo (novo vídeo/imagem)
- Expanda raio geográfico
```

---

### **Problema: "Zero conversões"**
```
Checklist de debug:
□ Formulário funciona? (teste você mesmo)
□ Pixel instalado? (Event Manager mostra PageView?)
□ Landing page abre? (teste no celular)
□ UTM parameters corretos? (verifique URL)
□ Público correto? (Orlando tem demanda?)

Se tudo ok:
⏳ Aguarde 5-7 dias (demora pra converter)
💰 Gaste pelo menos $100 antes de julgar
```
