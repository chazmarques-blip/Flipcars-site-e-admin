│                          🚨 TROUBLESHOOTING RÁPIDO                           │
└──────────────────────────────────────────────────────────────────────────────┘

    ❌ Build falha?
       → Verificar Root Directory = "backend"
       → Ver Build Logs no Railway
    
    ❌ DATABASE_URL missing?
       → PostgreSQL rodando?
       → Reiniciar serviço backend
    
    ❌ CORS error?
       → FRONTEND_URL tem 3 domínios separados por vírgula?
    
    ❌ 502 Bad Gateway?
       → PORT=3001 configurado?
       → Ver Application Logs
    
    ❌ SSL certificate pending?
       → Aguardar DNS propagar (5-30 min)
       → Verificar: nslookup api.flipcars.us
    
    ❌ Migrations falham?
       → DATABASE_URL está correta?
       → PostgreSQL está rodando?
    
    ❌ Não encontro Root Directory?
       → OK! O railway.toml já cuida disso
       → Continue para o próximo passo
