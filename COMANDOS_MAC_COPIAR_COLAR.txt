═══════════════════════════════════════════════════════════
COMANDO 1: Ir para Desktop
═══════════════════════════════════════════════════════════

cd ~/Desktop

(Apertar ENTER)

═══════════════════════════════════════════════════════════
COMANDO 2: Baixar projeto (SE JÁ TEM, PULAR PARA COMANDO 3)
═══════════════════════════════════════════════════════════

git clone https://github.com/chazmarques-blip/Flipcars-site-e-admin.git

(Apertar ENTER e aguardar download)

═══════════════════════════════════════════════════════════
COMANDO 3: Entrar na pasta (SE JÁ TEM O PROJETO)
═══════════════════════════════════════════════════════════

cd Flipcars-site-e-admin && git pull && cd migration_backup

(Apertar ENTER)

═══════════════════════════════════════════════════════════
COMANDO 3-ALT: Entrar na pasta (SE ACABOU DE BAIXAR)
═══════════════════════════════════════════════════════════

cd Flipcars-site-e-admin/migration_backup

(Apertar ENTER)

═══════════════════════════════════════════════════════════
COMANDO 4: Instalar biblioteca Python
═══════════════════════════════════════════════════════════

pip3 install psycopg2-binary

(Apertar ENTER e aguardar 1-2 minutos)

Se der erro, tentar:

python3 -m pip install psycopg2-binary

═══════════════════════════════════════════════════════════
COMANDO 5: Executar migração
═══════════════════════════════════════════════════════════

python3 migrate.py

(Apertar ENTER)

Quando perguntar:
"Continuar com a migração? [s/N]:"

DIGITE: s
(Apertar ENTER)

═══════════════════════════════════════════════════════════
🌐 ATUALIZAR RAILWAY (no navegador)
═══════════════════════════════════════════════════════════

1. Abrir Safari: https://railway.app
2. Login
3. Clicar: "My Truck Backend"
4. Clicar: "Variables" (menu lateral)
5. Encontrar: "DATABASE_URL"
6. Clicar: "Edit" (ícone lápis)
7. APAGAR valor antigo
8. COLAR valor novo (Command + V)
9. Clicar: "Save" ou "Update"
10. Clicar: "Deploy" → "Redeploy"
