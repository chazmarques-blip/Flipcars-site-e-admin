## 💰 CÁLCULO DE ROI:

### **Fórmula:**
```
ROI = (Revenue - Cost) / Cost × 100%

Exemplo:
- Cost: $350 (primeira semana)
- Leads: 5 leads
- Cost per Lead: $70
- Conversion para venda: 40%
- Vendas: 2 carros
- Ticket médio: $2,500
- Revenue: $5,000
- ROI: ($5,000 - $350) / $350 × 100% = 1,328% 🚀
```

## ⚠️ PROBLEMAS COMUNS E SOLUÇÕES:

### **Problema 1: "Low search volume"**
**Solução:** Normal para keywords muito específicas. Aguarde 30 dias.

### **Problema 2: "Below first page bid"**
**Solução:** Aumente Max CPC em 30-50%.

### **Problema 3: "Low Quality Score"**
**Solução:** 
1. Melhorar relevância dos anúncios
2. Usar keywords nos headlines
3. Melhorar landing page experience

### **Problema 4: Muitas impressões, poucos clicks**
**Solução:** 
1. Melhorar anúncios (mais atraentes)
2. Adicionar preços/promoções
3. Usar mais extensões

### **Problema 5: Muitos clicks, poucas conversões**
**Solução:**
1. Revisar landing page
2. Simplificar formulário
3. Adicionar provas sociais
4. Verificar se telefone está visível
