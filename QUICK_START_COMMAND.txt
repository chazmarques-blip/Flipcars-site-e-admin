🔥 PROBLEMAS COMUNS E SOLUÇÕES
================================================================================

1. Login falha:
   → Verificar Vercel env vars no dashboard
   → Limpar cache: Cmd+Shift+R ou Ctrl+Shift+R
   → Verificar vercel.json NÃO tem env hardcoded

2. Backend não conecta DB:
   → Verificar DATABASE_URL no Railway
   → Verificar SSL está habilitado: ssl: { rejectUnauthorized: false }

3. Vercel não atualiza:
   → Forçar redeploy no dashboard
   → Fazer dummy commit: echo "// cache" > file.txt
   → Verificar build ID mudou

4. Tabelas não existem:
   → Rodar migrations: npm run migration:run
   → Ou usar TypeORM synchronize() temporariamente
   → Verificar seeds rodaram: npm run seed
